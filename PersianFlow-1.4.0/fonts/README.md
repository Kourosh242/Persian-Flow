# فونت‌های بسته‌بندی‌شده در Persian Flow 1.4.0

هر ۱۵ فونت این پوشه **متن‌باز و قابل بازتوزیع** است و از منبع رسمی طراح یا پروژه دریافت شده است. لایسنس کامل هر فونت در پوشه‌ی [`licenses/`](./licenses/) قرار دارد. فونت‌های تجاری مانند ایران‌سنس، ایران‌یکان، دانا و بی‌نازنین عمداً در این بسته وجود ندارند.

در اجرا فقط فونتی که کاربر انتخاب کرده است لود می‌شود؛ مجموع اندازه‌ی فایل‌های woff2 حدود ۱٫۲۲ MiB است، اما فونت‌های غیرفعال هزینه‌ی بارگذاری ندارند.
