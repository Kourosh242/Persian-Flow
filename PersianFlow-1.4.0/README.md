## ✨ ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| 🔢 **فارسی‌سازی اعداد، حتی هنگام تایپ** *(جدید در v1.4.0)* | تاگل سوم پاپ‌آپ، پیش‌فرض خاموش: ارقام لاتین داخل متن فارسی به «۰۱۲۳۴۵۶۷۸۹» تبدیل می‌شوند. کد، لینک، URL، رمز، فیلدهای تایپ و متن انگلیسی‌محور مستثنا هستند؛ با خاموش‌کردن، مقدار اصلی دقیقاً برمی‌گردد. |
| 🎨 **۱۵ فونت فارسی متن‌باز** | از چرخ‌دنده ⚙️ انتخاب کنید: وزیرمتن (پیش‌فرض)، استعداد، میخک، ساحل، صمیم، شبنم، پرستو، ناهید، گندم، تنها، بهداد، کاتیبه، لاله‌زار، آمیتا و نستعلیق. هر فونت پیش‌نمایش زنده دارد و فقط فونت فعال لود می‌شود. |
| 🧱 **فقط متن‌ها RTL می‌شوند، نه کل صفحه** | گاردهای ساختاری جلوی راست‌چین‌شدن wrapperها، ردیف‌های flex، منوها و کنترل‌های سایت را می‌گیرند؛ چیدمان اصلی دست‌نخورده می‌ماند. |
| 🧩 **خطوط فارسیِ دارای چیپ کد** | خطی که بین کلماتش `code` یا چیپ inline دارد یکپارچه و خوانا راست‌چین می‌شود؛ خود چیپ کد همیشه LTR و مونواسپیس باقی می‌ماند. |
| 🧱 **چت‌های طولانی AI** | صف موتاسیون، sweep جبرانی، پیمایش افزایشی، تحلیل پنجره‌ای و کش امضا از جاافتادن پیام‌ها در گفتگوهای بزرگ جلوگیری می‌کنند. |
| 🧾 **جدول‌ها و لیست‌های ترکیبی** | بلوک‌های متنی فارسی‌محور یکدست قضاوت می‌شوند؛ آیتم‌های انگلیسی و ساختارهای چیدمانی جهت ارثی ناخواسته نمی‌گیرند. |
| 🧠 **تشخیص هوشمند فارسی/انگلیسی** | شروع فارسی همیشه RTL است؛ متن لاتین‌محور فقط با سهم کافی فارسی RTL می‌شود و در غیر این صورت LTR و صرفاً فونت‌دار می‌ماند. |
| 😀 **ایموجی و علائم** | ایموجی‌ها خنثی شمرده می‌شوند و متن‌هایی مثل «سلام 😂 چطوری؟» درست نمایش داده می‌شوند. |
| ⌨️ **فیلدها و contenteditable** | input، textarea و ادیتورهای contenteditable با `dir=auto` هنگام تایپ فارسی راست‌چین می‌شوند؛ فارسی‌سازی اعداد هم بدون پرش کرسر انجام می‌شود. |
| 🕳️ **Shadow DOM** | shadow rootها و وب‌کامپوننت‌های تازه‌ساخته کشف، استایل‌دهی و پایش می‌شوند. |
| 🔒 **فونت داخلی و مصون از CSP** | فونت‌ها داخل همین بسته‌اند و با مبدأ `chrome-extension://` لود می‌شوند؛ حتی `font-src 'none'` مانعشان نمی‌شود. |
| 🎛️ **سه کنترل مستقل** | تاگل‌های راست‌چین، فونت و اعداد بدون ریلود روی تب‌های باز اعمال می‌شوند و تنظیمات در `chrome.storage.sync` می‌مانند. |

## ⚡ بهینه‌سازی‌های v1.4.0

- تحلیل تک‌پاس `charCode` بدون regex و کش امضای متن برای جلوگیری از پردازش تکراری.
- صف موتاسیون با حذف گره‌های تکراری، بودجه‌ی هر فریم و sweep جبرانی.
- پیمایش افزایشی و تحلیل پنجره‌ای برای صفحه‌های سنگین و پاسخ‌های بسیار طولانی.
- توقف کامل پردازش در تب پنهان و پیش‌لود فونت فعال برای کاهش مصرف و چشمک fallback.
- اعمال و بازگردانی زنده‌ی RTL، فونت و اعداد؛ نیازی به رفرش صفحه نیست.

## 📦 نصب

1. فایل [`PersianFlow-1.4.0.zip`](https://github.com/Kourosh242/Persian-Flow/releases/download/1.4.0/PersianFlow-1.4.0.zip) را دانلود و اکسترکت کنید، یا از پوشه‌ی آماده‌ی همین بسته استفاده کنید.
2. به `chrome://extensions` یا `edge://extensions` بروید.
3. **Developer mode** را روشن کنید.
4. **Load unpacked** را بزنید و پوشه‌ی `PersianFlow-1.4.0` را انتخاب کنید.

> ⚠️ اگر نسخه‌ی قدیمی دارید، پیش از نصب آن را حذف کنید. تنظیمات ذخیره‌شده‌ی تاگل‌ها و فونت از طریق `chrome.storage.sync` حفظ می‌شوند.

## 🎛️ استفاده

روی آیکن کلیک کنید:

- **راست‌چین کردن متن** — پیش‌فرض: روشن
- **فونت فارسی (وزیرمتن)** — پیش‌فرض: روشن؛ برای تغییر فونت روی چرخ‌دنده ⚙️ بزنید.
- **فارسی‌سازی اعداد** — پیش‌فرض: خاموش؛ فقط اعداد متن فارسی را تبدیل می‌کند.

تغییرات هر سه کنترل بلافاصله و بدون ریلود اعمال می‌شوند. انتخاب فونت هم با پیش‌نمایش زنده در همان پاپ‌آپ انجام می‌شود.

## 🔐 حریم خصوصی و سازگاری

- Manifest V3؛ سازگار با Chrome، Edge و مرورگرهای مبتنی بر MV3.
- دسترسی‌ها: `storage` برای تنظیمات و cache آپدیت، `alarms` برای بررسی شش‌ساعته و `notifications` برای اعلان نسخه‌ی جدید.
- پردازش متن کاملاً محلی است و هیچ متن یا داده‌ی کاربر ارسال نمی‌شود.
- فونت‌ها و منطق اصلی آفلاین کار می‌کنند؛ تنها شبکه‌ی اختیاری، بررسی آخرین ریلیز عمومی GitHub است.
- تزریق فونت و CSS زیر CSPهای سخت‌گیرانه، حتی `font-src 'none'`، طراحی و اعتبارسنجی شده است.
