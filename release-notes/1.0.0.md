# 🎉 Persian Flow 1.0.0 — اولین انتشار

> **Persian Flow** راست‌چین‌سازی خودکار پیام‌ها و متن‌های فارسی در هر وب‌سایت + فونت **وزیرمتن** داخلی است — سبک، آفلاین، مصون از CSP و بدون شکستن چیدمان سایت‌ها.

📦 **دانلود:** [`persian-flow-V1.0.0.zip`](https://github.com/Kourosh242/Persian-Flow/releases/download/1.0.0/persian-flow-V1.0.0.zip)

---

## ✨ قابلیت‌های این نسخه

### 🔤 فونت وزیرمتن کاملاً داخلی
- وزیرمتن متغیر (وزن ۱۰۰–۹۰۰) از داخل پکیج اکستنشن لود می‌شود — **بدون نیاز به اینترنت**.
- تزریق `@font-face` با آدرس مطلق `chrome-extension://` و `adoptedStyleSheets`؛ سایت‌هایی مثل GitHub که با CSP جلوی فونت خارجی را می‌گیرند، هیچ اثری ندارند.

### ⟵ راست‌چین‌سازی هوشمند و ایمن
- تشخیص ترکیب فارسی/انگلیسی: متن فارسیِ غالب راست‌چین می‌شود؛ جمله‌ی انگلیسیِ دارای کلمه‌ی فارسی فقط فونت می‌گیرد.
- هدف‌گیری **نزدیک‌ترین کانتینر متنی**، نه کل سایت — بلاک‌های چیدمانی (flex/grid/جدول‌ها) دست‌نخورده می‌مانند.
- استفاده از `unicode-bidi: plaintext` به‌جای `direction` روی بلوک‌ها تا لی‌آوت حباب‌های چت نشکند.

### 💬 پشتیبانی از وبِ امروز
- چت‌ها، سشن‌ها و سایدبار سایت‌های AI (ساختارهای flex و spanهای تودرتو).
- ایموجی‌ها خنثی شمرده می‌شوند؛ فونت ایموجی خراب نمی‌شود.
- Shadow DOM و وب‌کامپوننت‌های تازه‌نصب‌شده با پروب سبک کشف می‌شوند.
- فیدها و استریم زنده‌ی پیام با MutationObserver بهینه پایش می‌شوند.

### ⌨️ فیلدهای هوشمند
- `input` / `textarea` / `contenteditable` هنگام تایپ فارسی با `dir=auto` بومی راست‌چین می‌شوند و با پاک‌شدن متن به حالت سایت برمی‌گردند.

### 🔔 اعلان آپدیت
- مقایسه‌ی تگ آخرین ریلیز گیت‌هاب با نسخه‌ی نصب‌شده در پاپ‌آپ؛ کش ۶ ساعته و بدون پرمیشن اضافه.

### ⚡ بهینه برای سیستم‌های ضعیف
- تحلیل تک‌پاس `charCode` بدون regex + کش امضای متن (`WeakMap`).
- حذف گره‌های تکراری صف موتاسیون و سقف پردازش در هر فریم.
- اسکن اولیه با تأخیر ۱۵۰ms و توقف کامل پردازش در تب پنهان (مصرف ۰٪).

## 🧪 تست
- ۴۱+ تست خودکار jsdom و صفحه‌ی تست محلی `test-page.html` با CSP سخت‌گیرانه‌ی شبیه GitHub (۹ سناریو).

## 📦 نصب
1. zip پیوست را اکسترکت کنید.
2. در `chrome://extensions` حالت **Developer mode** را روشن کنید.
3. با **Load unpacked** پوشه‌ی اکسترکت‌شده را انتخاب کنید.

## 🔐 دسترسی‌ها
- تنها دسترسی: `storage` · Manifest V3 · پردازش تماماً لوکال و آفلاین.
