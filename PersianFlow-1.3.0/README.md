# Persian Flow

راست‌چین‌سازی خودکار **پیام‌ها و متن‌های فارسی** در وب‌سایت‌ها + **۱۱ فونت فارسی متن‌باز قابل‌انتخاب** (وزیرمتن، استعداد، ساحل، شبنم و…) — سبک و بهینه برای سیستم‌های ضعیف، بدون نیاز به اینترنت و سازگار با سخت‌گیرانه‌ترین محدودیت‌های امنیتی (CSP).

## ✨ ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| 🎨 **۱۱ فونت فارسی متن‌باز (جدید v1.2.0)** | از چرخ‌دنده ⚙️ در پاپ‌آپ: وزیرمتن (پیش‌فرض)، استعداد، میخک، ساحل، صمیم، شبنم، پرستو، ناهید، گندم، تنها، بهداد — هر کدام با پیش‌نمایش زنده، بدون تب جدید، اعمال فوری بدون ریلود. همه با لایسنس SIL OFL از مخازن رسمی طراحان. |
| 🔒 **فونت داخلی و آفلاین** | فونت از داخل پکیج اکستنشن لود می‌شود؛ سایت‌هایی مثل کلود و چت‌جی‌پی‌تی که با CSP جلوی فونت خارجی می‌گیرند هیچ اثری ندارند. ورژن تزریقی با آزمایش زنده اثبات شده (حتی زیر `font-src 'none'`). |
| 🧱 **پایداری RTL در چت‌های خیلی طولانی AI (v1.3.0)** | سکونِ RTL روی پیام‌های انتهایی گفتگوهای طولانی برطرف شد (سرریز صف موتاسیون + شبکه‌ی اطمینان تمام‌سندی)، کهنگی علائم روی فلیپِ زبان پاک می‌شود، ظرفهای چند‌بلوک مستقل قضاوت می‌شوند و فونت مونواسپیسِ کد حفظ می‌ماند. |
| 🧾 **جداول/لیست‌های شماره‌دار بدون به‌هم‌ریختگی** | الگوریتم یونیکود بین جزیره‌های LTR/RTL هرگز ترتیب را قیل نمی‌کند — بلوک متنیِ فارسی‌محور (LI/TD/…) یکدست علامت می‌گیرد (با محافظ منوها). |
| 🛡️ **استایل مصون از CSP** | CSS از مسیر مانیفست کروم تزریق می‌شود (نه با JS) — حتی سخت‌گیرانه‌ترین `style-src` هم نمی‌تواند جلویش را بگیرد. |
| 🧠 **تشخیص هوشمند ترکیب فارسی/انگلیسی** | مثل استاندارد بومی `plaintext` به «اولین کاراکتر معنادار» نگاه می‌شود: شروع فارسی → راست‌چین (حتی با کلمات لاتین زیاد در میان)، شروع لاتین → فقط فونت. |
| 🎯 **فقط محتوا، نه کل سایت** | نزدیک‌ترین کانتینر متنی هدف گرفته می‌شود؛ بلاک‌های بزرگ چیدمانی هرگز RTL نمی‌شوند، پس چیدمان سایت‌ها نمی‌شکند. |
| 😀 **پشتیبانی از ایموجی** | ایموجی‌ها خنثی در نظر گرفته می‌شوند؛ پیام «سلام 😂 چطوری؟» کامل راست‌چین می‌شود و فونت ایموجی هم خراب نمی‌شود. |
| 💬 **چت‌ها، سشن‌ها و سایدبار سایت‌های AI** | ساختارهای flex و spanهای تودرتو (الگوی رایج arena.ai و ابزارهای مشابه) پشتیبانی می‌شود. |
| ⌨️ **فیلدها هوشمند** | input/textarea/contenteditable با `dir=auto` بومی موقع تایپ فارسی راست‌چین می‌شوند و با پاک شدن، به حالت سایت برمی‌گردند. |
| 🕳️ **Shadow DOM** | وب‌کامپوننت‌های تازه‌نصب‌شده با پروب سریع کشف و پوشش داده می‌شوند. |
| ⚡ **بهینه برای سیستم ضعیف** | تحلیل تک‌پاس بدون regex، کش امضای متن، حذف گره‌های تکراری صف، اسکن دوره‌ای فقط وقتی صفحه تغییر کرده، توقف کامل در تب پنهان. |

## ⚡ بهینه‌سازی‌های این نسخه (پاسخ به مشکل کندی)

- **تحلیل تک‌پاس charCode:** تشخیص فارسی/لاتین و «اولین حرف قوی» در یک حلقه و بدون regex — چندین برابر سریع‌تر.
- **کش امضای متن (WeakMap):** کانتینری که محتواش عوض نشده، هرگز دوباره تحلیل یا دست‌کاری نمی‌شود — مهم‌ترین بهبود برای چت‌های فعال.
- **صف موتاسیون هوشمند:** گره‌هایی که جدشان هم در صف است حذف می‌شوند؛ سقف پردازش ۱۵۰ گره در هر فریم؛ سرریز صف با اسکن دوره‌ای جبران می‌شود.
- **توقف در تب پنهان:** وقتی تب مخفی است هیچ کاری انجام نمی‌شود (۰٪ مصرف).
- **اسکن اولیه با تأخیر ۱۵۰ms:** رندر اولیه‌ی صفحه قفل نمی‌شود.
- **شاخص‌های واقعی:** صفحه با ۱۴۵۰ المان و ۶۸۰ کانتینر فارسی → پردازش اسکن اولیه و استریم ۱۰۰ تغییر، هر کدام در کسری از ثانیه.

## 📦 نصب

1. `PersianFlow-1.3.0.zip` را اکسترکت کنید (یا از پوشه آماده `persian-flow/` استفاده کنید).
2. به `chrome://extensions` بروید.
3. **Developer mode** را روشن کنید.
4. **Load unpacked** → پوشه `persian-flow` را انتخاب کنید.

> ⚠️ اگر نسخه قدیمی را دارید، ابتدا حذفش کنید.

## 📁 ساختار

```
persian-flow/
├── manifest.json      # MV3 — تزریق JS + CSS (css از اینجا صورت می‌گیرد)
├── content.js         # منطق: اسکن، تشخیص، RTL، Observer
├── styles.css         # کلاس‌ها (تزریق از مانیفست؛ @font-face با آدرس مطلق از JS می‌آید)
├── popup.html|js      # پنل تنظیمات + بررسی آپدیت گیت‌هاب
├── fonts/             # وزیرمتن متغیر wght 100–900 (~۱۰۲KB)
├── icons/
└── test/              # تست‌های خودکار (jsdom)
```
