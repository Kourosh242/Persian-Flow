# Persian Flow

راست‌چین‌سازی خودکار **پیام‌ها و متن‌های فارسی** در وب‌سایت‌ها + **۱۱ فونت فارسی متن‌باز قابل‌انتخاب** (وزیرمتن، استعداد، ساحل، شبنم و…) — سبک و بهینه برای سیستم‌های ضعیف، بدون نیاز به اینترنت و سازگار با سخت‌گیرانه‌ترین محدودیت‌های امنیتی (CSP).

## ✨ ویژگی‌ها

| ویژگی | توضیح |
|---|---|
| 🧱 **پایداری RTL در چت‌های خیلی طولانی AI (v1.3.0)** | سکونِ RTL روی پیام‌های انتهایی گفتگوهای طولانی برطرف شد (سرریز صف موتاسیون + شبکه‌ی اطمینان تمام‌سندی تا ۵۰هزار گره / ۲میلیون کاراکتر)، کهنگی علائم روی فلیپِ زبان پاک می‌شود، ظرفهای چند‌بلوک مستقل قضاوت می‌شوند و فونت مونواسپیسِ کد حفظ می‌ماند. |
| 🎨 **۱۱ فونت فارسی متن‌باز (v1.2.0)** | از چرخ‌دنده ⚙️ در پاپ‌آپ: وزیرمتن (پیش‌فرض)، استعداد، میخک، ساحل، صمیم، شبنم، پرستو، ناهید، گندم، تنها، بهداد — هر کدام با پیش‌نمایش زنده، بدون تب جدید، اعمال فوری بدون ریلود. همه با لایسنس SIL OFL از مخازن رسمی طراحان. |
| 🔒 **فونت داخلی و آفلاین** | فونت از داخل پکیج اکستنشن لود می‌شود؛ سایت‌هایی مثل کلود و چت‌جی‌پی‌تی که با CSP جلوی فونت خارجی می‌گیرند هیچ اثری ندارند. ورژن تزریقی با آزمایش زنده اثبات شده (حتی زیر `font-src 'none'`). |
| 🧾 **جداول/لیست‌های شماره‌دار بدون به‌هم‌ریختگی** | الگوریتم یونیکود بین جزیره‌های LTR/RTL هرگز ترتیب را قیل نمی‌کند — بلوک متنیِ فارسی‌محور (LI/TD/…) یکدست علامت می‌گیرد (با محافظ منوها). |
| 🛡️ **استایل مصون از CSP** | CSS از مسیر مانیفست کروم تزریق می‌شود (نه با JS) — حتی سخت‌گیرانه‌ترین `style-src` هم نمی‌تواند جلویش را بگیرد. |
| 🧠 **تشخیص هایبرید ترکیب فارسی/انگلیسی** | شروع فارسی → همیشه راست‌چین (حتی با کلمات لاتین زیاد در میان)؛ شروع لاتین → راست‌چین فقط اگر سهم فارسی ≥ ۳۵٪ باشد؛ وگرنه فقط فونت. |
| 🎯 **فقط محتوا، نه کل سایت** | نزدیک‌ترین کانتینر متنی هدف گرفته می‌شود؛ بلاک‌های بزرگ چیدمانی هرگز RTL نمی‌شوند، پس چیدمان سایت‌ها نمی‌شکند. |
| 😀 **پشتیبانی از ایموجی** | ایموجی‌ها خنثی در نظر گرفته می‌شوند؛ پیام «سلام 😂 چطوری؟» کامل راست‌چین می‌شود و فونت ایموجی هم خراب نمی‌شود. |
| 💬 **چت‌ها، سشن‌ها و سایدبار سایت‌های AI** | ساختارهای flex و spanهای تودرتو (الگوی رایج arena.ai و ابزارهای مشابه) پشتیبانی می‌شود؛ حباب کاربر به لبه راست می‌چسبد. |
| ⌨️ **فیلدها هوشمند** | input/textarea/contenteditable با `dir=auto` بومی موقع تایپ فارسی راست‌چین می‌شوند و با پاک شدن، به حالت سایت برمی‌گردند. |
| 🕳️ **Shadow DOM** | وب‌کامپوننت‌های تازه‌نصب‌شده با پروب سریع کشف و پوشش داده می‌شوند. |
| 🔔 **اعلان آپدیت** | سرویس‌ورکر هنگام استارت‌آپ و هر ۶ ساعت تگ آخرین ریلیز را چک می‌کند: نشان «↑» + نوتیفیکیشن + پیام در پاپ‌آپ. |
| ⚡ **بهینه برای سیستم ضعیف** | تحلیل تک‌پاس بدون regex، کش امضای متن، حذف گره‌های تکراری صف، اسکن دوره‌ای فقط وقتی صفحه تغییر کرده، توقف کامل در تب پنهان. |

## 🧰 تغییرات نسخه ۱.۳.۰

پایداری کامل RTL — چهار اصلاح ریشه‌ای (جزئیات در [`CHANGELOG.md`](CHANGELOG.md)):

| # | باگ | درمان |
|---|---|---|
| ۱ | **سکون RTL روی پیام‌های انتهایی چت‌های طولانی** (گزارش claude.ai) | FIX-K: سرریز صف = خالی‌شدن + sweep دی‌بانس‌شده؛ سقف اسکن ۵۰هزار گره / ۲میلیون کاراکتر |
| ۲ | **کهنگی علائم روی فلیپ زبان** | FIX-L: بازارزیابی اجداد علامت‌خورده تا ۶ سطح |
| ۳ | **قضاوت ترکیبی ظرف‌های چندبلوک** | FIX-M: هر بلوک مستقل (فارسی RTL، انگلیسی تمیز) |
| ۴ | **فونت مونواسپیس کد می‌پرید** | FIX-N: `pre`/`code`/Monaco/CodeMirror → پشته‌ی مونواسپیس |

آزمون‌ها: **۱۳۷ jsdom** + **۳۰ E2E تعاملی** — مجموع **۲۶۱ تست سبز**.

## 📦 نصب

1. `PersianFlow-1.3.0.zip` را اکسترکت کنید (یا از همین پوشه‌ی آماده استفاده کنید).
2. به `chrome://extensions` بروید.
3. **Developer mode** را روشن کنید.
4. **Load unpacked** → همین پوشه را انتخاب کنید.

> ⚠️ اگر نسخه قدیمی را دارید، ابتدا حذفش کنید. تنظیمات (تاگل‌ها و انتخاب فونت) حفظ می‌شود.

## 🎛️ استفاده

روی آیکن کلیک کنید:

- **راست‌چین کردن متن** — پیش‌فرض: روشن
- **فونت فارسی (وزیرمتن)** — پیش‌فرض: روشن؛ لیبل نام فونتِ فعال را نشان می‌دهد
- **چرخ‌دنده ⚙️ کنار لوگو** — انتخاب یکی از ۱۱ فونت با پیش‌نمایش زنده

تغییرات بلافاصله و بدون ریلود روی همه‌ی تب‌ها اعمال می‌شود و با `chrome.storage.sync` بین دستگاه‌ها همگام می‌ماند.

## 📝 نسخه‌ها

شرح کامل تغییرات در **[CHANGELOG.md](CHANGELOG.md)**.

- **۱.۳.۰** — پایداری کامل RTL: رفع سکون پیام‌های انتهایی چت‌های طولانی (FIX-K)، پاک‌سازی علائم کهنه روی فلیپ زبان (FIX-L)، قضاوت مستقل ظرف‌های چندبلوک (FIX-M)، حفظ فونت مونواسپیس کد (FIX-N). ۱۳۷ تست jsdom + ۳۰ E2E — ۲۶۱ تست سبز.
- **۱.۲.۰** — انتخاب ۱۱ فونت متن‌باز از پاپ‌آپ با پیش‌نمایش زنده؛ رفع به‌هم‌ریختگی جدول/لیست؛ رفع جاماندن پاراگراف در استریم طولانی؛ رجیستری `pf-fonts.js`.
- **۱.۱.۰** — تشخیص هایبرید متن ترکیبی؛ تاگل‌های مستقل و فوری؛ حفظ گره‌های استریم؛ یکپارچگی پیام‌های flex؛ اعلان آپدیت با سرویس‌ورکر.
- **۱.۰.۰** — اولین انتشار: فونت داخلی ضد-CSP، تشخیص هوشمند، هدف‌گیری فقط محتوا، پشتیبانی ایموجی/چت/Shadow DOM، بهینه برای سیستم‌های ضعیف.

## 🔐 دسترسی‌ها و حریم خصوصی

- Manifest V3 — کروم/اج؛ آزمون‌شده روی Chrome 148.
